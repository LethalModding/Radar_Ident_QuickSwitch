# Install and dependencies

## r2modman or Thunderstore Mod Manager

1. Install Radar Ident QuickSwitch from Thunderstore.

## Manual download

1. Download Radar Ident QuickSwitch from Thunderstore.
2. Extract the zip into your BepInEx directory.

## Dependencies

When installing manually, install [BepInExPack (version 5.4.2100 or higher)](https://thunderstore.io/c/lethal-company/p/BepInEx/BepInExPack/) first.
